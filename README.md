# 🚀 Go - Complete Guide (Learning Project)

Welcome to my Go learning journey! 🐹 This repository contains various projects, exercises, and examples that I've been building while learning the Go programming language.

## 📁 Repository Structure

Here's an overview of the topics and projects covered in this repository:

- **[`go-basics`](./go-basics)** 🧠: Core fundamentals of Go, including variables, data types, control structures, and syntax.
- **[`functions`](./functions)** 🛠️: Deep dive into Go functions, multiple return values, closures, and more.
- **[`arrray-slices-maps`](./arrray-slices-maps)** 📦: Working with Go's built-in data structures for managing collections of data (Arrays, Slices, and Maps).
- **[`structs`](./structs)** 🏗️: Defining and using custom types with structs and methods.
- **[`structs-practice`](./structs-practice)** 🏋️: Hands-on exercises and practice using structs in Go.
- **[`gorutines`](./gorutines)** ⚡: Introduction to concurrency in Go using Goroutines and Channels.
- **[`price-calculator`](./price-calculator)** 🧮: A practical project demonstrating calculations and logic.
- **[`rest-api`](./rest-api)** 🌐: Building a RESTful API using Go, handling HTTP requests, and routing.

## 🛠️ Prerequisites

To run the code in this repository, you'll need to have Go installed on your machine.

- [Download and install Go](https://go.dev/doc/install)

## 🚀 Running the code

Navigate to any of the subdirectories and use the standard Go commands to run the applications.

```bash
cd go-basics
go run main.go
```
